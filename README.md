This is the asynforge platform! You can create various complex sites without writing code on this platform! How to create a site? You can drag elements to the viewport with the cursor using gizmos, styles are also given through the right menu, and all styles in static html css can be given!

The platform is not limited to the frontend, of course, a backend and a 60% security wall are also built! The backend is mainly controlled via routes via api.asynforge.site.

You enter the asynforge.site site, at the top you will see the login, dashboard, and search screens! Through login, you enter your old account by sending a request to the backend and the login system is protected, through sign up you open a new account, you need a username, email and password, when you enter your email, a confirmation code will be sent to your email, you confirm it by entering it! You enter the dashboard where you can manage projects, see your statistics, create groups and configure your account. your projects will come to you in real time from the backend, of course, special attention is also paid to IDOR! you can open your projects in the editor page and edit them, and you can save them to the backend again using the save button, and you can get the code of the site you created using the export button! the profile menu will be like this, where everyone can see their own and others' profiles, routes will be like this asynforge.site/profile/your.username and you can open someone's username via the url asynforge.site/profile/owner, knowing your friend's username, you can follow his projects, of course, the projects he made public! your every move will be saved to the backend database!
